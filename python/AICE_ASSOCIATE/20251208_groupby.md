# groupby?
특정 컬럼을 기준으로 데이터를 "그룹"으로 나눈 뒤, 그룹 단위로 통계 계산을 수행하는 기능.

예를 들어:
* 성별(Sex)별 평균 나이 → "남자 평균 나이", "여자 평균 나이"
* 객실 등급(Pclass)별 생존율 → "1등급 생존율", "3등급 생존율"
* 도시별 매출 합계 → "서울 매출", "부산 매출"

즉, "집단별 통계"를 만들고 싶을 때 무조건 사용하는 도구.


# groupby 동작 원리
실제로 다음 3단계를 거친다.

1. spilt
기준 컬럼을 보고 데이터를 여러 그룹으로 나눈다.
ex) Sex → [Male 그룹], [Female 그룹]

2. Apply
각 그룹에 대해 평균, 합, 개수, 최소/최대 등 원하는 연산을 수행한다.

3. Combine
계산 결과를 하나의 표(DataFrame 또는 Series)로 합쳐 출력한다.


# 기본 문법

1) 가장 기본 형태: size()
그룹별 **행 개수(빈도)** 를 알고 싶을 때 사용.
```python
df.groupby("Sex").size()
```

예시 출력:
```
Sex
female    314
male      577
dtype: int64
```

* "여자 몇 명", "남자 몇 명"처럼 단순 빈도 확인에 매우 유용.

2) 단일 컬럼에 대해 평균(mean) 계산
```python
df.groupby("Pclass")["Fare"].mean()
```

예시 출력
```
Pclass
1    84.15
2    20.66
3    13.67
Name: Fare, dtype: float64
```

* 각 등급별 평균 요금 확인
* groupby 이후 ["컬럼"]을 붙이는 이유: 분석 대상 변수 지정을 위함.


3) 여러 컬럼에 대해 통계 게산
```python
df.groupby("Sex")[["Age", "Fare"]].mean()
```

| Sex    | Age 평균 | Fare 평균 |
| ------ | ------ | ------- |
| female | …      | …       |
| male   | …      | …       |

-> 집단별 다중 통계량 비교할 때 유용.

4) reset_index()로 DataFrame 형태로 변환
groupby **결과는 기본적으로 Series로 출력**됨.
이걸 DataFrame 형태로 바꾸면 정렬, 시각화 등에 활용 가능해진다.

```python
df.groupby("Sex")["Survived"].mean().reset_index()
```

# groupby 응용 문법

1) 여러 컬럼으로 그룹화
```python
df.groupby(["Sex", "Pclass"])["Survived"].mean()
```

예시 출력:
```
Sex     Pclass
female  1    0.96
        2    0.92
male    1    0.36
        3    0.13
```

<br>

2) agg()로 여러 통계량 출력
기본 문법 ㅠ이후 가장 빠르게 배워야 하는 문법.
```python
df.groupby("Pclass")["Fare"].agg(["mean", "max", "min"])
```

| Pclass | mean | max | min |
| ------ | ---- | --- | --- |


<br>

3) 특정 컬럼 여러 통계 + 여러 컬럼 통합
```python
df.groupby("Sex").agg({
    "Age": ["mean", "median"],
    "Fare": ["max", "min", "mean"]
})
```
