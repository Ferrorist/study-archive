# get_dummies - 원-핫 인코딩(One-Hot Encoding)

범주형(col)이 문자(ex. "male", "female")일 때, 모델이 숫자로 해석할 수 있도록<br>
**각 카테고리를 0/1 컬럼으로 분리**해주는 방식.<br>
머신러닝에서 가장 기본적이면서도 자주 사용된다.

```python
import pandas as pd
df = pd.DataFrame({
    "Sex": ["male", "female", "female", "male"],
    "Embarked": ["S", "C", "Q", "S"]
})

encoded = pd.get_dummies(df, columns=["Sex", "Embarked"], drop_first=False)
print(encoded)
```

## drop_first 옵션
* `drop_first=True` : 더미 변수 함정(dummy variable trap) 방지용
* A, B, C가 있으면 한 개만 제거하여 다중공선성(Multicollinearity) 방지
* 시험 응용에서는 **drop_first는 필요 없는 경우가 많음**

<br>

# Label Encoding - 범주를 숫자로 직접 변환
문자형 데이터를 0, 1, 2, ... 등 정수로 변환하는 방식.<br>
주로 **순서가 없는 범주형에는 부적절(숫자의 크기 의미가 생기기 때문)**<br>
하지만 **트리 기반 모델(RandomForest, XGBoost)** 에서는 사용 가능.

```python
from sklearn.preprocessing import LabelEncoder

le = LabelEncoder()
df["Sex_encoded"] = le.fit_transform(df["Sex"])
```

결과
* male -> 1
* female -> 0


# get_dummies vs Label Encoding
| 방법             | 특징                      | 주로 사용       |
| -------------- | ----------------------- | ----------- |
| get_dummies    | 컬럼 여러 개로 분리. 숫자 의미 없음   | 선형 모델, 로지스틱 |
| Label Encoding | 하나의 숫자 값. 숫자의 크기 의미가 생김 | 트리 모델       |

# groupby 다중 컬럼
groupby는 **데이터를 특정 기준으로 묶어 집계**하는 도구.<br>
여러 컬럼을 기준으로 묶을 수도 있음.


## 기본 예제
```python
df.groupby(["Sex", "Pclass"])["Survived"].mean()
```


**출력 형태**<br>
계층적 인덱스로 반환
```
Sex     Pclass
female  1         0.96
        2         0.92
male    1         0.36
        3         0.13
```

<br>

# agg() - 여러 통계값을 한 번에 계산.
groupby와 함께 자주 사용됨. 여러 컬럼에 대해 여러 집계를 한 번에 계산 가능.

```python
df.groupby("Pclass").agg({"Fare": ["mean", "max", "min"]})
```

**해석**<br>
* 1등석 승객 평균 요금
* 1등석 승객 최대 요금
* 1등석 승객 최소 요금
* 2·3등석도 동일 계산

<br><br>

# sort_values() - 정렬
오름차순/내림차순, 여러 컬럼 정렬.

```python
df.sort_values("Fare") # 오름차순
df.sort_values("Fare", ascending=False) # 내림차순
df.sort_values(["Pclass", "Fare"], ascending=[True, False]) # 여러 컬럼 정렬
```
