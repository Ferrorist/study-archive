# Z-Score 개념 이해

## Z-Score이 필요한 이유
데이터 분석에서 자주 부딪히는 질문이 이것이다.
> "이 값, 다른 값들에 비해 **유난히 튀는 값 - 이상치**인가?

예를 들어서,
* 반 평균 키가 170cm인데, 어떤 사람이 190cm이다.
* 반 평균 점수가 70점인데, 어떤 학생이 100점이다.

문제는, 데이터마다 단위도 다르고, 분산도 다 다르다는 것이다.

그래서 "얼마나 튀었는지"를 공통된 기준으로 표현할 필요가 있다. 그 "공통된 기준"이 바로 **Z-score** 이다.
이 Z-Score는 **표준편차 단위로 표현한 거리**이다.

## Z-score 공식

$$Z = \frac{x - \mu}{\sigma}$$

* $Z$ : Z-Score 또는 표준 점수 (Standard Score)
* $x$ : 개별 데이터 값 (Observed Value)
* $\mu$ : 모집단의 평균 (Population Mean)
* $\sigma$ : 모집단의 표준편차 (Population Standard Deviation)

<details>
<summary>
※ 분산 | 표준편차 계산?
</summary>
    1. 평균 계산<br>
    2. 각 데이터 값에서 평균을 빼서 편차를 계산<br>
    3. 2에서 구한 각 편차를 제곱한다.<br>
    4. 제곱된 편차들을 모두 더한 후 이를 평균을 구한다. → 분산<br>
    5. 4에서 구한 분산에 양의 제곱근을 씌운다. → 표준편차<br>
</details>

<br>

이를 한 줄로 말하면:

> **데이터 값 x가 평균에서 표준편차 몇 개만큼 떨어져 있냐** 를 계산한 값

### Z-Score 직관적으로 이해해보기

#### "거리"라는 개념
1. 먼저 데이터에서 평균을 뺀다. → $x - \mu$
* 평균보다 크면 양수, 작으면 음수
* "평균에서 얼마나 떨어져 있는지" 거리 정보
<br>
2. 1번의 값을 표준편차로 나눈다 → $\frac{x -\mu}{\sigma}$

* "표준편차를 1 단위로 봤을 때, 몇 단위로 떨어져 있냐?"
* 이러면 어떤 데이든 '스케일'이 같아진다.

<br><br>

예시로 감을 잡자면,<br>
* 평균 키: 170cm, 표준편차: 5cm라고 한다면,
  * 175cm → $Z = \frac{175 - 170}{5} = 1$ → 평균보다 $1\sigma$ 큰 값
  * 160cm → $Z = \frac{160 - 170}{5} = -2$ → 평균보다 $2\sigma$ 작은 값

여기서,
* Z = 0 : 평균과 똑같은 값
* Z = 1 : 평균보다 표준편차 1개만큼 크다.
* Z = -2 : 평균보다 표준편차 2개만큼 작다.

라는 할 수 있다. 이렇게 Z-Score를 보면,
* 값 자체(160, 175, 190)가 아니라,
* "평균에서 얼마나 튀었냐"에만 집중할 수 있다.

#### 스케일을 맞춰주는 역할 (표준화)

Z-Score 변환을 다른 말로 **표준화(Standardization)** 라고 한다.

여러 특징이 있을 때:
* 어떤 건 단위가 `원`, 어떤 건 `cm`, 어떤 건 `나이` 이런 식이라면
* 그냥 쓰면 범위가 큰 특성이 모델에 더 크게 반영되는 문제가 생긴다.

그래서 각 컬럼에 대해
$$x' = \frac{x - \mu}{\sigma}$$

이렇게 변환하면,
* 평균이 0 근처, 표준편차 1 근처인 값들로 변환된다.
* 스케일이 맞춰져서 비교와 학습에 유리하다.

<br>

### 정규분포와 Z-score의 관계
Z-score는 특히 **정규분포(종 모양 분포)**와 궁합이 좋다.

데이터가 대략 정규분포를 따른다고, 가정하면:
* 약 **68%** 의 데이터가 Z-score: -1 ~ +1 사이
* 약 **95%** 의 데이터가 Z-score: -2 ~ +2 사이
* 약 **99.7%** 의 데이터가 Z-score: -3 ~ +3 사이

그래서 관습적으로:
* $|Z| > 2$ → 좀 많이 튄 값
* $|Z| > 3$ → 이상치(outlier) 후보로 많이 취급.<br>
이게 바로 3-sigma rule 이라고 부르는 개념이다.

## IQR (Interquartile Range)

### Z-Score의 한계
Z-Score는 정규분포(종 모양)을 가정할 때 특히 잘 작동하지만 그렇지 않은 경우 문제가 발생한다.
예를 들면,

* 한쪽으로 치우친 분포(편향)
* 극단적으로 튀는 값 몇 개
* 이상하게 꼬리가 긴 분포(long-tail)
* 비정규 분포

현실 데이터는 이런 경우가 매우 많다.<br>
이런 환경에서는 **평균과 표준편차가 이상치의 영향을 크게 받아 흐트러지는 문제**가 생긴다.
<br>

예시를 한 번 보자.<br>
데이터가 `[10, 12, 11, 13, 12, 200]` 이렇게 있다면
* 평균은 이상치(200)에 끌려서 크게 올라가 버림
* 표준편차도 같이 커지고 결국 Z-score가 이상치를 잘 못 잡게 된다.

이 문제를 해결하기 위해 등장한 개념이:
> 중앙값(Median)을 기준으로 하는 "IQR 기반 이상치 탐지"

평균 대신 중앙값, 표준편차 대신 사분위 범위(IQR)를 사용하므로 이상치의 영향을 거의 받지 않는다. -> 강건성이 매우 높음.

### IQR(Interquartile Range)의 정확한 정의
IQR은 이름 그대로:
> 데이터의 "1사분위수(Q1)" 와 "3사분위수(Q3)" 사이의 범위

$$IQR = Q3 - Q1$$
