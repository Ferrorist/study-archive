# Z-Score 개념 이해

## Z-Score이 필요한 이유
데이터 분석에서 자주 부딪히는 질문이 이것이다.
> "이 값, 다른 값들에 비해 **유난히 튀는 값 - 이상치**인가?

예를 들어서,
* 반 평균 키가 170cm인데, 어떤 사람이 190cm이다.
* 반 평균 점수가 70점인데, 어떤 학생이 100점이다.

문제는, 데이터마다 단위도 다르고, 분산도 다 다르다는 것이다.

그래서 "얼마나 튀었는지"를 공통된 기준으로 표현할 필요가 있다. 그 "공통된 기준"이 바로 **Z-score** 이다.
이 Z-Score는 **표준편차 단위로 표현한 거리**이다.

## Z-score 공식

$$Z = \frac{x - \mu}{\sigma}$$

* $Z$ : Z-Score 또는 표준 점수 (Standard Score)
* $x$ : 개별 데이터 값 (Observed Value)
* $\mu$ : 모집단의 평균 (Population Mean)
* $\sigma$ : 모집단의 표준편차 (Population Standard Deviation)

<details>
<summary>
※ 분산 | 표준편차 계산?
</summary>
    1. 평균 계산<br>
    2. 각 데이터 값에서 평균을 빼서 편차를 계산<br>
    3. 2에서 구한 각 편차를 제곱한다.<br>
    4. 제곱된 편차들을 모두 더한 후 이를 평균을 구한다. → 분산<br>
    5. 4에서 구한 분산에 양의 제곱근을 씌운다. → 표준편차<br>
</details>

<br>

이를 한 줄로 말하면:

> **데이터 값 x가 평균에서 표준편차 몇 개만큼 떨어져 있냐** 를 계산한 값

### Z-Score 직관적으로 이해해보기

#### "거리"라는 개념
1. 먼저 데이터에서 평균을 뺀다. → $x - \mu$
* 평균보다 크면 양수, 작으면 음수
* "평균에서 얼마나 떨어져 있는지" 거리 정보
<br>
2. 1번의 값을 표준편차로 나눈다 → $\frac{x -\mu}{\sigma}$

* "표준편차를 1 단위로 봤을 때, 몇 단위로 떨어져 있냐?"
* 이러면 어떤 데이든 '스케일'이 같아진다.

<br><br>

예시로 감을 잡자면,<br>
* 평균 키: 170cm, 표준편차: 5cm라고 한다면,
  * 175cm → $Z = \frac{175 - 170}{5} = 1$ → 평균보다 $1\sigma$ 큰 값
  * 160cm → $Z = \frac{160 - 170}{5} = -2$ → 평균보다 $2\sigma$ 작은 값

여기서,
* Z = 0 : 평균과 똑같은 값
* Z = 1 : 평균보다 표준편차 1개만큼 크다.
* Z = -2 : 평균보다 표준편차 2개만큼 작다.

라는 할 수 있다. 이렇게 Z-Score를 보면,
* 값 자체(160, 175, 190)가 아니라,
* "평균에서 얼마나 튀었냐"에만 집중할 수 있다.

#### 스케일을 맞춰주는 역할 (표준화)

Z-Score 변환을 다른 말로 **표준화(Standardization)** 라고 한다.

여러 특징이 있을 때:
* 어떤 건 단위가 `원`, 어떤 건 `cm`, 어떤 건 `나이` 이런 식이라면
* 그냥 쓰면 범위가 큰 특성이 모델에 더 크게 반영되는 문제가 생긴다.

그래서 각 컬럼에 대해
$$x' = \frac{x - \mu}{\sigma}$$

이렇게 변환하면,
* 평균이 0 근처, 표준편차 1 근처인 값들로 변환된다.
* 스케일이 맞춰져서 비교와 학습에 유리하다.

<br>

### 정규분포와 Z-score의 관계
Z-score는 특히 **정규분포(종 모양 분포)**와 궁합이 좋다.

데이터가 대략 정규분포를 따른다고, 가정하면:
* 약 **68%** 의 데이터가 Z-score: -1 ~ +1 사이
* 약 **95%** 의 데이터가 Z-score: -2 ~ +2 사이
* 약 **99.7%** 의 데이터가 Z-score: -3 ~ +3 사이

그래서 관습적으로:
* $|Z| > 2$ → 좀 많이 튄 값
* $|Z| > 3$ → 이상치(outlier) 후보로 많이 취급.<br>
이게 바로 3-sigma rule 이라고 부르는 개념이다.

<br><br><br>

## IQR (Interquartile Range)

### Z-Score의 한계
Z-Score는 정규분포(종 모양)을 가정할 때 특히 잘 작동하지만 그렇지 않은 경우 문제가 발생한다.
예를 들면,

* 한쪽으로 치우친 분포(편향)
* 극단적으로 튀는 값 몇 개
* 이상하게 꼬리가 긴 분포(long-tail)
* 비정규 분포

현실 데이터는 이런 경우가 매우 많다.<br>
이런 환경에서는 **평균과 표준편차가 이상치의 영향을 크게 받아 흐트러지는 문제**가 생긴다.
<br>

예시를 한 번 보자.<br>
데이터가 `[10, 12, 11, 13, 12, 200]` 이렇게 있다면
* 평균은 이상치(200)에 끌려서 크게 올라가 버림
* 표준편차도 같이 커지고 결국 Z-score가 이상치를 잘 못 잡게 된다.

이 문제를 해결하기 위해 등장한 개념이:
> 중앙값(Median)을 기준으로 하는 "IQR 기반 이상치 탐지"

평균 대신 중앙값, 표준편차 대신 사분위 범위(IQR)를 사용하므로 이상치의 영향을 거의 받지 않는다. -> 강건성이 매우 높음.

### IQR(Interquartile Range)의 정확한 정의
IQR은 이름 그대로:
> 데이터의 "1사분위수(Q1)" 와 "3사분위수(Q3)" 사이의 범위

$$IQR = Q3 - Q1$$

여기서 사분위수는 다음을 뜻한다.
* $Q1$ (1st quartile)<br>
데이터 중 하위 25% 지점

* $Q2$ (Median)<br>
데이터 중 중앙값(50%)

* $Q3$ (3rd quartile)<br>
데이터 중 상위 25% 지점

IQR은 즉, "가운데 50%의 값이 어느 범위 안에 들어있는가?" 라고 이해하면 된다.

<br>

### IQR이 주는 중요한 의미
IQR은 데이터의 핵심적인 중간 50% 부분만을 본다.<br>
극단값이 있어도 IQR은 거의 흔들리지 않는다.

그래서:<br>
* 이상치가 있어도 기준이 변질되지 않음.
* 비정규분포에서도 안정적으로 작동함.
* 편향된 분포에서도 잘 작동함.

→ Z-score보다 현실 데이터에 더 강하다.

<br>

### IQR 기반 이상치 탐지의 핵심 아이디어
데이터의 중앙 50% 범위(IQR)가 있다면,<br>**그보다 너무 벗어난 값들은 이상치 후보**라고 보는 방식이다.

#### 1.5 x IQR 기준 (가장 널리 사용됨)
이상치 범위를 다음과 같이 정의한다.
$$Lower Bound = Q1 - 1.5 * IQR$$
$$Upper Bound = Q3 + 1.5 * IQR$$

그리고 다음 조건에 해당하면 "이상치" 라고 판단한다.

* 값 < $Lower Bound$
* 값 > $Upper Bound$

#### 3 x IQR (더 강한 이상치 조건)
$$Lower Bound = Q1 - 3 * IQR$$
$$Upper Bound = Q3 + 3 * IQR$$

실무에서도 가끔 사용된다.

<br><br>

### IQR 이상치 판단 예시
데이터가 다음과 같다고 해보자.
```csharp
[10, 12, 13, 15, 17, 18, 25, 80]
```

1. 정렬<br>
이미 정렬됨.

2. 사분위수 구하기<br>
* Q1 = 12.5 정도
* Q3 = 21.5 정도
(정확히 구하는 방법은 분포에 따라 약간 달라진다.)

3. IQR 계산
$$IQR = 21.5 - 12.5 = 9$$

4. 이상치 기준 계산 (1.5배 기준)

$$Lower Bound = 12.5 - 1.5 * 9 = -1$$


$$Upper Bound= 21.5 + 1.5 * 9 = 35$$


5. 이상치인지 계산
* 80 > 35 → **이상치**
* 나머지 값들은 정상


### IQR의 방식
* 중앙값 기반

이상치 영향을 거의 안 받음.<br>
극단값이 있든 없든 Q1과 Q3는 거의 변하지 않음. 따라서 안정적이다.


* 구현이 매우 쉬움

Pandas 한 줄로 Q1, Q3 을 쉽게 구함.<br>
공식도 단순하며, boxplot 시각화와 직관적으로 연결됨.
```python
Q1 = df['fare'].quantile(0.25)
Q3 = df['fare'].quantile(0.75)
IQR = Q3 - Q1
lower, upper = Q1 - 1.5 * IQR, Q3 + 1.5 * IQR
df[(df['fare'] < lower) | (df['fare'] > upper)] # 이상치 판별
```

## IQR + Z-Score 같이 활용

### 왜 IQR 과 Z-Score를 같이 활용하는가?
두 기법이 성격이 다름.

| 기법 | 강점 | 약점 |
| --- | --- | --- |
| IQR | 극단값에 강함(Robust),<br>분포 모양 상관없음 | 데이터 분포가 넓게 퍼져 있을 때<br>민감도 낮을 수 있음 |
| Z-Score | 분포 중심 흐름을 잘 반영,<br>표준화에 유리 | 이상치가 많은 데이터에서는 왜곡됨 |

실전에서는 데이터가 극단값도 섞여 있거나, 한쪽으로 치우지는 등 복잡한 경우가 많다.<br>
그래서 "이상치 탐지 → 비교 → 최종 선택 → 표준화" 흐름에서 두 방법을 보완적으로 사용한다.


### 함께 사용하는 대표적 케이스 3가지

#### 1. IQR로 1차 필터링 → Z-score로 2차 정밀 확인

(1) IQR로 극단적으로 튀는 값을 먼저 제거
 
 * 분포 전체를 흐뜨러뜨리는 강한 이상치 제거

(2) Z-Score로 남은 값들 중 경계선에 있는 값들 판단

 * $|Z| > 3$ 기준으로 정밀 탐지
 * 분포 상에서 "평균으로부터 너무 멀다"는 기준 추가 적용

<br>

#### 2. IQR로 이상치 후보 추출 → Z-Score로 정상/이상 경계 판단

* `Fare` 컬럼에 IQR 기준으로 이상치가 80개 나왔다면
* 모든 값을 제거하는 대신, Z-Score도 계산해서
  * $|Z| > 3$ → 확실한 이상치
  * $|Z|$ 가 2 ~ 3 사이 → 데이터 상황 보고 판단
  * $|Z| < 2$ → 단순히 분포가 넓어서 IQR에 걸렸을 가능성

> 이렇게 레이블링/스코어링 기반 판단이 가능하다.

<br>

#### 3. IQR은 이상치 탐지용 + Z-score는 표준화용

대부분 머신러닝 모델은 입력 스케일이 중요하다.

* 로지스틱 회귀
* SVM
* KNN
* 신경망 등

그래서 흐름이 다음과 같다.

(1) IQR로 이상치 제거 또는 조정
→ 이상치가 학습 과정 왜곡하는 걸 막음

(2) Z-score (StandardScaler) 로 전체 데이터 표준화
→ 스케일링 (평균 0, 표준편차 1)

## Boxplot으로 이상치 시각 확인

IQR 기반 이상치 탐지와 boxplot은 완전히 연결되어 있다.

### Boxplot의 구조부터 이해하기
```
      (이상치)
        ●     ●
     ──────────────   ← Upper Whisker (= Q3 + 1.5×IQR)
     |           |
Q3 ──┤           ├── Q3 (75% 지점)
     |           |
     |   Box     |   ← 박스 전체가 IQR 범위 (Q1 ~ Q3)
     |           |
Q2 ──┤-----------┤── Median (중앙값)
     |           |
Q1 ──┤           ├── Q1 (25% 지점)
     |           |
     ──────────────   ← Lower Whisker (= Q1 – 1.5×IQR)
        ●     ●
      (이상치)

```
* 박스(box) = Q1 ~ Q3 = 중간 50% 분포
* 박스 중앙선 = Medium (중앙값)
* 수염 (Whisker) = IQR의 1.5배 기준
* 수염 범위 밖의 점들 = **이상치**


### Pandas + Matplotlib으로 boxplot 그리기
```python
import matplotlib.pyplot as plt
import seaborn as sns

plt.figure(figsize=(6, 4))
sns.boxplot(x=df['fare'])
plt.title("Boxplot of Fare")
plt.show()
```
