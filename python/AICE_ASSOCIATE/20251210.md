# EDA(탐색적 데이터 분석)에서 시각화의 역할
수치만 보면 보이지 않는 것들이 그래프에서는 보일 수 있다.<br>

* 분포
  * 값이 한쪽으로 치우쳤는지 (왼쪽 / 오른쪽 꼬리)
  * 평균 근처에 몰려 있는지, 여러 봉우리가 있는지
* 이상치
  * 극단적으로 벗어난 값 (말도 안 되게 큰 값 / 작은 값)
* 변수 간 관계
  * X가 커질수록 Y도 같이 커지는지 (X-Y 관계)
  * 특정 그룹에서만 패턴이 다른지 (ex. 여성/남성, 생존/사망 등)


<br>

시각화를 다루기 전 공통 세팅 예시.
```python
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

# 데이터 로드
df = pd.read_csv("train.csv")

# 기본 전처리(너무 복잡하게 안 가고)
# Age, Fare에서 NaN 간단 처리 예시
df["Age"] = df["Age"].fillna(df["Age"].median())
df["Fare"] = df["Fare"].fillna(df["Fare"].median())
```

<br><br>

# `hist()` - 히스토그램: "분포 모양"
히스토그램은 특정 변수의 값들이 어떻게 분포되어 있는지 보여준다.<br>
구간(bin)을 여러 개로 나누고, 각 구간에 값이 몇 개씩 속하는지 세어서 막대 그래프로 나타낸다.<br>

주로 이러한 의문을 해결할 때 사용한다:
* 데이터가 한쪽으로 치우쳐 있는가?
* 어떤 값 근처에 값들이 몰려 있는가?
* 중간에 구멍(데이터 거의 없는 구간)이 있는가?

<br>

## 기본 문법 (matplotlib)
```python
plt.hist(df["Age"], bins=20) # matplotlib에 히스토그램 추가, bins : 구간(막대) 개수

plt.xlabel("Age")
plt.ylabel("Count")
plt.title("Age Distribution")
plt.show()
```

<br>

## Titanic 예시 응용 - 생존 여부에 따라 분포 비교
```python
survived = df[df["Survived"] == 1]["Age"]
not_survived = df[df["Survived"] == 0]["Age"]

plt.hist(survived, bins=20, alpha=0.5, label="Survived")
plt.hist(not_survived, bins=20, alpha=0.5, label="Not Survived")

plt.xlabel("Age")
plt.ylabel("Count")
plt.title("Age Distribution by Survival")
plt.legend()
plt.show()
```

여기서 볼 수 있는 것:<br>
* 특정 나이대(ex: 어린이, 노인)가 상대적으로 더 많이 살아남았는지
* 생존/사망 분포가 많이 겹치는지, 아닌지

<br><br>

# `boxplot()` - "분포 요약 + 이상치 + 그룹 비교"

## 박스플롯의 각 요소
* 박스 중앙선 → 중앙값(median)
* 박스 아래/위 → 1사분위 (Q1), 3사분위 (Q3)
* 박스 높이(Q3 - Q1) → IQR(Interquantile Range)
* 위 아래 '수염(whisker)' → 보통 Q1 - 1.5IQR ~ Q3 + 1.5IQR
* 수염 밖의 점들 → 이상치 후보

<br>

주로 이러한 의문을 해결할 때 사용한다:
* 평균 말고, 데이터가 어느 구간에 모여 있는가?
* 이상치가 많은가?
* 그룹 A와 B 중 어디가 값이 더 큰 편인가?

## 기본 문법 (seaborn 추천)
```python
sns.boxplot(x=df['Fare'])
plt.title("Fare Boxplot")
plt.show()
```

## 그룹별 비교 - 선실 등급(Pclass)별 Fare
```python
sns.boxplot(x="Pclass", y="Fare", data=df)
plt.title("Fare by Pclass")
plt.show()
```

보고 해석할 수 있는 것:<br>
* 1등석(Pclass=1)이 3등석(Pclass=3)보다 요금 분포가 더 높게 위치
* 이상치(아주 비싼 티켓)가 어느 등급에 몰려 있는가

<br><br>

# `scatter()` - 산점도: "두 변수 관계"

* x축: 한 변수
* y축: 다른 변수
* 각 점: 한 사람/한 샘플
* 패턴:
  * 대각선 모양 → 양의 상관 또는 음의 상관
  * 구름처럼 퍼져 있음 → 상관관계 약함
  * 특정 부분에 점이 몰려 있음 → 클러스터, 구간별 특징

## 기본 문법 (matplotlib)
```python
plt.scatter(df["Age"], df["Fare"])

plt.xlabel("Age")
plt.ylabel("Fare")
plt.title("Age vs Fare")
plt.show()
```

위의 코드를 통해 다음 질문에 대한 답을 할 수 있다.<br>
* 나이가 많을수록 더 비싼 티켓을 샀는가?
* 특정 나이/요금 구간에 데이터가 몰려 있는가?

### 생존 여부를 색으로 구분 (seaborn)
```python
sns.scatterplot(x="Age", y="Fare", hue="Survived", data=df)
plt.title("Age vs Fare by Survival")
plt.show()
```

여기서:<br>

* 같은 나이/요금대에서도 생존자가 더 많은 구간이 있는지
* 비싼 요금 + 특정 나이대 조합에서 생존율이 다른지 감이 온다.

<br><br>

# seaborn `pairplot()` - "여러 변수 관계를 한 번에 훑기"

## 개념
* 선택한 여러 변수들에 대해:<br>
  * 대각선(diagonal) : 각 변수의 **히스토그램/분포**
  * 나머지 칸: 변수 쌍마다 **산점도**
* hue를 주면 색으로 그룹을 나눌 수 있음.

즉, "이 변수들이 서로 어떤 식으로 연결되어 있는지" 전체 구조를 한 번에 보고 싶을 때 쓰는 도구이다.

<br>

## Titanic 예시
```python
cols = ["Age", "Fare", "Pclass", "Survived"]
sns.pairplot(df[cols], hue="Survived", diag_kind="hist")
plt.show()
```

여기서 볼 수 있는 것:<br>

* Age vs Fare, Age vs Pclass, Fare vs Pclass 등 **각 조합에서 생존 여부별 분포 차이**
* Pclass가 1인 사람들은 대체로 Fare가 높은지
* Age 분포가 생존자/비생존자 사이에서 미묘하게 다른지
